# Godskin

แอปบันทึกการซ้อมสร้างกล้าม 6 วัน/สัปดาห์ บล็อก 8 สัปดาห์ พร้อม double progression อัตโนมัติ

- กรอกน้ำหนัก/ครั้งทุกเซ็ต บันทึกอัตโนมัติ ครั้งหน้าแอปบอกว่าเพิ่ม คงไว้ หรือลด
- ตัวจับเวลาพักเริ่มเองเมื่อกรอกจำนวนครั้ง
- นับสัปดาห์ของบล็อกให้เอง (Re-entry → Build → Peak → Deload แล้ววนที่สัปดาห์ 3)
- บันทึกน้ำหนักตัว (ค่าเฉลี่ย 7 วัน) และ Check-in ตอนเช้า ถ้าฟื้นตัวไม่ทัน 3 วันติด ตัดเซ็ตลงให้
- ข้อมูลเก็บใน IndexedDB ของเครื่อง มี Export/Import JSON สำรอง ใช้ออฟไลน์ได้ (PWA)

## พัฒนา

```
npm test        # ทดสอบ logic ของ progression
npm run serve   # เปิดที่ http://localhost:8080
```

แก้ท่าหรือเซ็ตได้ที่ `js/program.js` ทุกครั้งที่แก้ไฟล์ ให้เปลี่ยน `VERSION` ใน `sw.js` เพื่อให้มือถือโหลดเวอร์ชันใหม่
